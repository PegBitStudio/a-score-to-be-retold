# A Score to Be Retold

A web work for the Permanence category. A circle is one day. A rust point is the present hour. Twelve sentences sit underneath, and only one is spoken today. The same piece is written out as plain instructions, so it can be performed with paper, two inks, and a clock after the browser is gone.

Nothing here needs a build step, a server, or an account. Open `index.html`. A reader’s extra sentence stays in their browser and in the link, not on a server.
